# GitHub repo metadata (paste by hand)

GitHub doesn't let a repo set its own "About" description/topics/social image from a committed file — these have to be pasted into the repo settings UI once. Copy-paste source for that, kept here so it doesn't have to be reinvented each time it changes.

